## 資料與工作規則

卡片固定四欄：核心概念、使用規則、操作步驟、原文例子。目標首行標籤為 `#七政四餘`；本機已完成 4,039 檔首行替換並驗證，遠端發佈遭自動審核拒絕，因此目前 GitHub 卡片仍是 `#七政四余`。階段 0 尚未全部完成。既有卡片正文在階段 0 保持逐字不變，僅更新首行標籤；不因跨書同文、圖表指標或同名異義而刪除卡片。

本專案不提交 PDF。盤面由使用者以其他排盤軟體產生後提供，技能不計算也不驗算盤面。回答範圍限於本庫卡片；缺載回答「資料中未載」。

各階段分開提交；每階段完成後回報，收到使用者確認才進入下一階段。現有 19 本完成並經確認前，不處理新增書籍。

## 階段 0 重跑檢查

執行：`python tools/stage0_audit.py`。逐檔比對基準提交，驗證搬移後的卡片只改首行、清單連結可用，且沒有追蹤 PDF；此檢查不代替後續原文及品質複核。
