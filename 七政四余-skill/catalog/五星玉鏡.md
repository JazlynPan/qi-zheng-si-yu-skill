# 《五星玉鏡》目錄與正文核對

PDF 共61頁，目錄分七卷；正文在第41頁再次題“卷之二”，該處內容為〈通玄賦〉及後接〈天官經〉，對應目錄卷六。不能把這個印題直接當作另一個卷二而漏掉內容。沒有另編連續章號，按正文篇目列49項（包含卷四〈總論〉及卷一〈干支神煞起例〉）。

## 目錄差異

- 水星的目錄頁碼印為“291”，正文第29頁。
- 多數後段頁碼較正文實際頁碼遲一頁：如目錄〈一命宮〉31，正文30；〈通玄賦〉42，正文41；〈天官經〉50，正文49；〈宮度分金骨髓〉53，正文52；〈流年論〉57，正文56；〈流年都天賦〉59，正文58。
- 目錄“論氣星”，正文“論炁”；目錄“八疾惡”，正文“八疾厄”；目錄“流年都天賦”，正文“流年賦（即流年都天賦）”。
- 目錄沒有單列〈干支神煞起例〉、第13頁附起例及卷四末〈總論〉。
- 卷六處正文卷號與目錄不同，已在上文如實標示。
