## 範圍與注意

24組、五題共120筆，含缺卡行；每筆均附年欄與值欄的原圖。原圖值與頁碼分開核，不依旬次或干支偏移代填。
狀態欄只反映本輪證據；頁碼錯與字值問題可能並存，詳見說明。空亡兩字按同格字集合核對，不自行改卡內原來的左至右書寫順序。
**版式例外：丙辰欄分題印「擎天」「遊奕」，不能一律說全圖未分。** 頁73丙子年欄破損，欄名沿用使用者辨欄，不冒充完整可見原刻。
歲殿與登籍共值不等於擎天／遊奕可單邊決定；原題歲駕亦不自動改為歲殿。

## 需要使用者決定

1. 逐筆確認原圖值與頁碼；所有更改仍未套用，缺卡亦未補。
2. 擎遊未分題的原圖是否採成對記錄；丙辰分題例外應另存，不與未分式混寫。
3. 丁丑、壬戌、戊申左旁字仍待原圖裁讀；不依對宮推值。
4. 分類統計採哪個明確定義；歷史數字與原圖前組法的差異已列，不強湊。
