# 催官、貴元等跨頁組抽查（已依使用者回覆更正）

## 更正原因

前版把物理大欄位置寫成題名：文魁等錯標年干支欄，科名錯標貴元欄；並用同一大裁切圖及同一問題，造成重複提問。現在題名、物理位置分列，每題用不同紅框。
前版科名裁切只到頁高51%，漏掉下方值字；已擴到60%。己巳貴元在目前底本影像右緣仍不完整，不聲稱補出了原字。
使用者已回覆27項（明示8、其餘與現值一致19），底本未確認1項；不改卡、不補卡。前版己卯及己巳官印的羅水暫讀撤回，按使用者確認的現值羅木記錄。
