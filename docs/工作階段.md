# 工作階段與順序

依使用者最新指示，階段 1 與階段 2 之間新增階段 1.5，並取消原階段 7。新增書籍統一在階段 1.5 補齊，再依2 → 4a → 3 → 4b → 5 → 6執行，不另安排追加新書流程。其餘來源、原文、刪除與分階段確認規則維持適用。

|階段|工作|
|---|---|
|0：核對與基準|核對書籍與卡片、建立基準標籤、整理結構、統一首行標籤。已完成。|
|1：補完目前19本|首輪補齊、四欄與出處結構核對已完成；保留事項見階段1報告。|
|1.5：雲端全庫補齊|未決事項保留、未驗收；依2026-11-26使用者授權先行階段2試跑。已盤點30份來源（29本PDF、1份Word），與帳本相符，無新增檔；各份均已有處理紀錄，河洛、命海、綱目仍核對中；階段尚未完成。|
|2：整理卡片|進行中：先試分類《五星捷要便覽》，待使用者確認後才跑全庫。不改卡檔；建立卡片分類.tsv，每卡恰好一個去向；異體字對照、去重候選、衝突與待核對清單；先1本試跑經確認再全庫。|
|4a：只出題與預期答案|先索取5–10個真實問題，回原PDF出75題，固定種子切60%訓練／40%驗證；抽看10題經使用者確認後才進階段3。|
|3：檢查與檢索|建立檢查及離線搜尋工具，全量檢查並抽查100張卡片。|
|4b：無Skill基準|獨立執行無Skill基準、引用檢查與token量測；缺失題保留分母。|
|5：完成Skill|建立索引、SKILL.md、倫理準則、盤面範本及提煉規範。|
|6：回跑評測|以新對話或子代理測試有Skill時的表現，依實際失敗修正。|

開始各階段前讀[階段規格](階段規格.md)，不列入新對話必讀；詳細驗收依該檔執行；階段4a、4b、5、6開始前另讀[評測協議](評測協議.md)，不列入新對話必讀。

## 階段1.5執行規則

來源資料夾：https://drive.google.com/drive/folders/1fpgv8Er56lFxlW4FJoYPE5UT_jg4E5iL

1. 完整列出資料夾及其可讀子資料夾中的書籍，記錄本次盤點時間與檔案清單，不以目前帳本19本為全部。
2. 對照 docs/來源清單.md，以檔案識別碼、檔名、PDF頁數及SHA256核對，區分已完成、部分完成、尚未處理與疑似異版；帳本不明者回查實際紀錄，不直接算完成。
3. 補完部分提煉的書籍，並對未處理書籍逐本進行文字層與頁碼核對、目錄與正文結構核對、逐節提煉、來源及四欄自檢，更新帳本與待核對清單。
4. 沿用既有原文照錄、臺灣繁體、四欄與PDF實際頁碼規則；不因尚未制定階段5的提煉規範而免除既有規則。規範建立後，新書依該文件處理。
5. 不自行替掃描版做OCR，不猜測無法讀取的內容；遇到無文字層或不可讀檔案須回報。疑似同書不同版本仍須先詢問使用者，不自行裁決。
6. 不刪卡、不提前做階段2的跨書整理；PDF原檔不提交git。每本書的結構核對與進度須可追查。
7. 補齊後再掃描一次雲端資料夾，把期間新增且尚未處理的書籍納入補齊；回報仍有阻礙的檔案，不把它們列為完成。
8. 階段1.5結束回報書籍總數、頁數、卡片數、完成與未完成清單。完成並經使用者確認後，才進入階段2；不以「19本已讀完」取代全庫補齊。

每個階段結束均先回報並等待使用者確認；後續工作依 [規則補充](規則補充.md) R1–R8。
