# 各階段規格
本檔只在各階段開始前讀，不列入新對話必讀。階段1.5完成並經使用者確認後，順序為2 → 4a → 3 → 4b → 5 → 6；本次不開始階段2。

## 通則
- 證據等級：E0腳本體檢；E1讀文件評分；E2獨立代理實跑並盲評；E3使用者用真實盤面實際使用。報告不得把低等級說成高等級。
- 階段6保留或回滾至少要E2；未經使用者使用，寫「未經使用者實用驗證」。
- 失敗分類取代R7三類：卡片缺漏／索引或搜尋問題／SKILL.md指示不足／題目或預期答案有誤／原文抽取或OCR問題。每筆標critical／major／minor並記錄證據。
- 保留R7處理方式：卡片缺漏回待核對清單及下一輪補卡；索引或搜尋問題改build_index.py或search.py；只有指示不足可改SKILL.md。預期答案修改須有獨立理由與紀錄；抽取或OCR問題核原頁，不猜補。
- 判分以機械斷言為主；評審判定與機械斷言不一致，交使用者看，不自行裁決。
- 階段4a、4b、5、6開始前另讀[評測協議](評測協議.md)，不列入新對話必讀。

## 階段2：分類與整理
- 建立qi-zheng-si-yu/references/variants.md，只收各書實際出現、可由原文對照確認的異體字，不憑記憶補。
- 不改卡檔、不刪卡；另存docs/卡片分類.tsv。
- 欄位：卡片檔名、書名、篇名、類別、去向、重複於。
- 類別：規則／命例／術語／單句詩訣／圖表待核對／其他；去向：可搜尋／圖表待核對／待我決定，每卡恰好一個去向，不得遺漏。
- 重複於：只有同書同頁完全重複才填保留的那張，其餘留空；不刪卡。
- 分類只依卡片標題與四欄，不憑記憶補；先試跑1本，結果與問題給使用者確認後才跑全庫。
- 建立去重候選、衝突及待核對清單；不同書說法並列，不自行裁決。

## 階段4a：只出題與預期答案
- 開始前向使用者索取5–10個真實問題；來源優先序：真實問題＞口述場景＞原書頁反推；全為反推時標「用文件出題考文件」。
- 存evals/questions.jsonl；欄位：id、類型、問題、預期要點、必須引用（書名＋頁碼）、取自哪本書哪一頁、split。
- 題型數量：查詢20、操作步驟10、誘導10、混淆10、應觸發10、不應觸發10、邊界5，共75題；盤面題待使用者提供。
- 題目應有書中特定說法、頁碼、各書差異，讓無知識庫模型可能答錯；基準無知識庫也全對者標「無區分度」，不計增益。
- 誘導題取自分類的圖表待核對及無文字層頁，答案明說「原文為圖表／未提取」；混淆題取自階段2衝突清單與去重候選，須分書列出。
- 預期答案必須回原PDF頁取得，不由卡片或Skill輸出反推。檢查項寫結果，不寫過程。
- 固定種子切60%訓練／40%驗證；驗證集在使用者確認版本前不得查看或據以修改。
- 每題型各寫一段判分規則：先機械斷言，再由不知道預期答案的獨立評審判讀，詳見評測協議。
- 題目寫完先給使用者抽看10題，確認後才進階段3。

## 階段3：檢查與檢索
- build_index.py連跑兩次，輸出逐位元組相同（R6）。
- search.py處理簡體輸入與variants.md；預設前10筆（R8）；單句詩訣卡同時回傳同書同篇前後各1張。
- 相關卡只依標題或術語表的明確共同詞，不自行推論關係。
- 命中：前10筆任一卡的出處書名等於預期書名，且頁碼範圍與預期頁重疊。只用訓練集調搜尋，驗證集不用於本階段；報命中率，不自行訂門檻。
- E0驗證腳本100%通過：首行標籤、四欄格式、內部連結可解析、cards.jsonl欄位完整、SKILL.md≤150行。
- E0另檢查description≤300字、關鍵資訊在前250字、第三人稱；SKILL.md引用檔案存在；無個人路徑、不寫死單一runtime的路徑或工具名（例如Claude Code、Codex）。
- 全量後抽查100張，每本至少3張，其餘按卡片數比例；每張回原PDF頁核對，報錯誤數與書名，有錯追同批次一併檢查。

## 階段4b：無Skill基準
- 依評測協議隔離資料、獨立實跑與盲評；結果存evals/baseline.md。
- 建立引用真實性自動檢查，量測name＋description常駐token及單題載入token（SKILL.md＋最多5卡）。
- 報計畫、完成、全部通過題數，缺失不剔分母；依協議分流增益，不自行訂門檻。
- 報告含門檻交使用者確認後才進階段5。

## 階段5：重寫Skill
- 整份重寫最初版qi-zheng-si-yu/SKILL.md；禁止「先讀 knowledge/ 目錄」指示，先跑search.py，再讀命中卡最多5張；最重要規則在最前。
- SKILL.md≤150行；description第三人稱、≤300字、關鍵資訊前250字，寫明觸發與不觸發。
- 路由：查概念／解讀盤面／問書。
- 回答範本：每條結論附《書名》第N頁；不同書分列；圖表待核對明說未提取；區分「書中如此說」與「對本盤的判定」，不得有預言式確定結論。
- 引文不足就說明不足，不補完整方法；依R4附命例並標「書中例子，僅供對照，非本盤判定」。
- references/chart-input.md缺欄位先問使用者、不猜；欄位定稿前須有使用者盤面，未提供時階段5開始前提醒。
- 建立docs/提煉規範.md（含R1）、references/書籍總覽.md（R2）、references/glossary.md（R3）、cards.jsonl命例類別（R4）、ETHICS.md；references與index均在Skill本體內。
- docs/覆蓋稽核.md先列約20–30項使用任務，依各書目錄與使用者真實問題（如星曜、宮位、格局、限運），不依卡片反推；逐項列對應卡及無卡任務。
- 同時核對每本書卡片去向與未被卡涵蓋頁；重大缺口標「草稿」，不得標已驗收。
- 最後在新對話、不看倉庫其他檔案跑觸發測試；細節依評測協議，寫入報告。

## 階段6：對照與修正
- 有Skill與baseline逐題對照，先訓練集、修改後驗證；最終驗證集只在最後跑一次，比較原始版與最終版。
- 每輪只驗證一個假設，引用具體失敗題與SKILL.md行號；最多3輪；順序：刪、改、移到references、最後才加。
- 至少E2：嚴格更好才保留；打平且更短才保留；打平沒變短就回滾。超上一版110%須指出修好的失敗檢查。
- git revert回滾，不硬重置；每輪結果含回滾假設追加evals/results.tsv，下輪先讀；連續2輪回滾停手交使用者決定。
- 不動區：原文照錄、引用格式、ETHICS.md、誘導題不得猜測；評審建議刪除也不執行，只記理由。
- 預期答案修改須獨立理由與紀錄，不為通過改答案；已看失敗題加入回歸集。
- 誘導與引用不捏造100%，critical失敗0；其他門檻由使用者看baseline後決定。
- 每輪git diff與結果交使用者審，不好就回滾；固定七段報告依評測協議，數字只取results.tsv與計票輸出。
