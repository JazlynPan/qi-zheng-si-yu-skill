## 資料與工作規則

卡片固定四欄：核心概念、使用規則、操作步驟、原文例子。首行標籤為 `#七政四餘`。階段 0 的基準標籤與首行替換提交已成功推送；先前遭自動審核阻擋的報告保留為歷史紀錄。既有卡片正文在階段 0 保持逐字不變，僅更新首行標籤；不因跨書同文、圖表指標或同名異義而刪除卡片。

本專案不提交 PDF。盤面由使用者以其他排盤軟體產生後提供，技能不計算也不驗算盤面。回答範圍限於本庫卡片；缺載回答「資料中未載」。

各階段分開提交；本次依使用者要求，先將尚未完成的階段 1 工作稿建立進度提交。每階段完成後回報，收到使用者確認才進入下一階段。階段 1 完成後，先進行階段 1.5「雲端全庫補齊」，把雲端資料夾中尚未提煉或提煉未完成的書籍補完；完成並經確認後，才進入階段 2。取消原階段 7；本批新增書籍統一納入階段 1.5，不在階段 2 之後另跑一次追加新書流程。
