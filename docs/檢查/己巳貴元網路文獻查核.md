# 己巳貴元：外書查核（2026-11-19）

## 結論與限制

目前綱目第84頁可取得影像的右緣未完整顯示己巳貴元值字；放大或改裁切不能造出影像以外的原字。不能把外書值寫成綱目原圖讀值。
本次找到直接的己巳年條轉錄「貴元木、科名土」，另有不同表目巳年條的水星記載；不強行選成底本答案。

## 不混用的說法

外書中的貴元、馬元、地驛及宮主、度主說法須按各書原文辨別，不能因名詞相同就把所有星曜取法合成一條。
本次先查到水星線索，後查到更直接的己巳年條木值，已保留兩者而未強行改答案。書名《星學大成》亦不自動等同本庫《星平大成》。

## 處理結果

- 己巳貴元：底本未確認；外書年條暫記木作待核參考，並保留水星條文的取法差異。
- 己巳科名土是使用者本次核圖結果，與外書轉錄相符；不因此推論外書其他欄都正確。
- 其他27項已按使用者回覆記錄；本次不改卡、不補卡。四張科名缺卡另列補卡清單，不把未建卡當原圖空白。
