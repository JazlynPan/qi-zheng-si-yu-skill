# 《星命總括》結構與版本核對

PDF共75頁。此整理本合併四庫本與《星學大成》本，無獨立目錄，也未按卷重新標出三卷。四庫提序稱原書三卷，不能據此把本PDF強分為三部分。正文主要篇目30次，另有十二宮子目12次；兩處〈論倒限〉來源、位置不同，均列出，不擅合為同篇。沒有連續章號。

## 版本與篇目差異

- 整理者以《星學大成》本編排為主，合入四庫本內容；兩版篇次不同。
- 四庫本沒有〈步天經〉與子宮安命論；本PDF以大成本補入，不能當成PDF缺章。
- 四庫本獨有的後附內容自第61頁後起，包括〈星經〉等；整理者註明多出自《喬拗五星》及其他書。
- 〈星命總括原序〉在《星學大成》本題〈天星標本序〉；〈玉堂寶書五星斷〉、〈七政論〉等在四庫本無相應篇名。
- 〈二十八條斷例〉的四庫本尾部缺數條，大成本有後續。本PDF保留後續；不把“二十八”當作其他版本實存條數。
- 〈太陰倒限〉等在兩版本的歸篇位置不同，整理者已有明注；卡片保留本PDF各段出處。
- 本文出現相反異文，如“因妻致富／因妻家敗”“尤急／尤吉”等，全部保留版次，不擇一替作者訂正。
