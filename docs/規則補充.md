R1【立即生效，含階段 1.5 剩餘的書】卡片粒度與空殼：
   - 一張卡只放一個概念、一條規則或一個命例。
   - 如果某段落整理後，只剩書名頁碼加「原文未提及」或「原文以圖表呈現」，
     而沒有任何實質文字，不要建立卡片檔。改記入該書 docs/catalog 的
     「圖表與待核對頁」清單，欄位：概念名稱、書名、頁碼、原因。
   - 卡片中只有部分欄位缺載是正常的，照舊標示，不受此限。
   - 既有的空殼卡不刪、不改，留到階段 2 分類為「圖表待核對」。
   - 階段 5 建立 docs/提煉規範.md 時，把此規則寫入。

R2【階段 5】新增 qi-zheng-si-yu/references/書籍總覽.md（放在 skill 本體內，
   因為回答時會用到）：每本書一列，欄位：書名、
   書中自述的作者與年代（書中沒寫就填「書中未載」，不得用你的記憶補）、
   主要內容、體例、與其他書的關係（同源、異版、收錄、引用，
   依書中明文或比對結果）、頁數、卡片數。
   使用方式：SKILL.md 寫明何時讀（見檔案使用表）；
   每新增一本書，補上該書一列，並在 docs/狀態.md 記錄。

R3【階段 5】新增 qi-zheng-si-yu/references/glossary.md（術語表）：
   術語、對應卡片 id、書名與頁碼。只收卡片標題或書中明確定義的詞，
   不寫你自己的解釋。
   使用方式：SKILL.md 寫明「遇到不熟的術語或搜尋無結果，
   先查術語表，再依對應卡片 id 讀取卡片」。

R4【階段 2 與 5】命例：在 index/cards.jsonl 的「類別」中新增「命例」

   使用方式：解讀盤面流程加一步，查詢後如有同星曜、同宮位的命例，
   附在回答最後，標明「書中例子，僅供對照，非本盤判定」。

R5【階段 4】評測新增兩種題型：
   - 誘導題：問題對應到「圖表待核對」的卡片，或無文字層的頁面。
     正確回答是「該處原文為圖表或無文字層，內容未提取」，不得猜測。
   - 混淆題：同一個詞在不同書意思不同，回答必須分開列出，不能混成一個。

   差異要列出並修正，驗證結果寫進回報。

R7【階段 6】評測失敗要分類寫入 evals/失敗紀錄.md：
   卡片缺漏／索引或搜尋問題／SKILL.md 指示不足。
   只有「指示不足」可以修改 SKILL.md；「卡片缺漏」回到待核對清單處理，
   並列入下一輪補卡；「索引或搜尋問題」改 build_index.py 或 search.py。
