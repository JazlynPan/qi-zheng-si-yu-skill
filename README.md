# 七政四餘原文資料庫

**不是摘要，而是一座有書名、有頁碼的七政四餘原文資料庫。**
AI 回答時會指出出自哪本書、第幾頁；書裡沒寫就回答「資料中未載」。

## 為什麼做這個

- 不必在多本書裡反覆翻找同一個詞。
- 每個說法都能回到原書核對。
- 不同書的說法分開保存，避免混在一起。

## 卡片長什麼樣

取自[一日復來（蘭臺妙選）](qi-zheng-si-yu/knowledge/一日復來（蘭臺妙選）.md)，已截短：

```markdown
#七政四餘

## 核心概念

《司臺曆數袖裡璇璣》第75頁“蘭臺妙選上篇”：

一日復來：自本位順數至第七位是也。如甲子見庚午，乙丑見辛未，丙寅見壬申之類。
```

## 怎麼運作

1. 逐頁閱讀，把書中內容整理成卡片。
2. 建立索引，查詢時只找相關卡片。
3. 回答只依卡片，不同書的說法並列。

## 範例

以下只有預期格式；測試通過前不放真實輸出。

- 你問：〈使用者的問題〉
- 它怎麼查：〈搜尋相關卡片，讀取命中內容〉
- 它回答：〈結論要點〉／〈依據：書名、頁碼、卡片編號〉／〈各書說法〉／〈資料未載之處〉

## 它不做什麼

不排盤，盤面由其他軟體產生後提供；不預測，只轉述書中怎麼說，不替書下結論。
